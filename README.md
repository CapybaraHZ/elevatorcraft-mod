# ElevatorCraft — Minecraft Fabric 电梯模组文档页

在线访问：https://capybarahz.github.io/elevatorcraft-mod/

## 仓库说明

- `index.html`：完整文档页，单文件、内联 CSS、无外部静态依赖，可直接双击本地打开
- 托管方式：GitHub Pages，来源为 `main` 分支根目录（`/(root)`）
- 更新流程：修改 `index.html` 后提交到 `main`，Pages 会自动重新构建，约 30～90 秒生效

## 页面内容

ElevatorCraft v1.0.3 的完整实现方案：轿厢、外呼面板、电梯门、刷卡鉴权、监控、楼层检测、门锁与管理终端，包含代码结构、关键代码、合成配方与材质方案。

- 目标版本：Minecraft 1.21.8
- Fabric Loader 0.20.1 / Fabric API 0.136.1+1.21.8 / Java 21
- 产物：`elevatorcraft-1.0.3.jar`
